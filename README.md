# WifiScope
An esp-32 based Wifi-Signal Strength Analayzer

This code is for one to assess signal strength using an esp-32's inbuilt WiFi 2.5Ghz signals.
The program shows the signal name, signal strength, signal security, and channel on which the signal runs;

To set it up : 

*You will need to install the PlatformIO extension which helps directly code to your micro-controllers from VS-Code;
Download the code, initialize VS-code with PlatformIO and run the code;
You shall be seeing your esp-32's local website address;
Connect to your esp-32's locally held WiFi named WiFiScope and open the website address.

Hardware Required : An esp-32 which can minimum read WiFi 2.5Ghz signals;
